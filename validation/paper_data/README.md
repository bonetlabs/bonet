# Paper results

Every number of the paper's evaluation, recomputed from the raw data in `raw/`. Generated by `paper_data.py`: do not edit, run it again.

- Δ pps: throughput change, `PDR_variant / PDR_plain − 1` (for times, `t_plain / t_variant − 1`).
- Δ time: time per packet change, `t_variant / t_plain − 1` (for PDRs, `PDR_plain / PDR_variant − 1`).
- ± is the 95% confidence interval (Student t over the repetitions; Welch for differences).
- Cases: Plain eBPF (`baseline/`), Inlined APIs (`framework/`, `BNT_INLINE_ALL=1`), BONet (`framework/`, asm globals: the default), BONet with C globals, the kernel's own configuration.

Updating: run the experiment, then `paper_data.py run [RUN_ID]`, `paper_data.py verifier DIR` or `paper_data.py code` (see the docstring), and commit `raw/` and this file.
